# Security Skill 🔐

## Description
Ye skill authentication aur app security ke liye best practices enforce karta hai.

## Objective
Ensure secure web application by handling CORS, HTTPS, token expiry, secret management aur sensitive configurations.

## Capabilities

1. **CORS**
   - Backend ke liye cross-origin requests configure kare

2. **HTTPS Assumptions**
   - All production requests should be HTTPS
   - Enforce secure cookies

3. **JWT Expiry & Refresh**
   - Token expiry handling
   - Refresh token mechanism

4. **Secrets Handling**
   - Environment variables ke through secrets manage kare
   - No hardcoding of secrets

5. **Env Config**
   - Config files aur .env variables maintain kare
   - Different configs for dev, staging, production

## Usage
- Used by Auth Skill aur Backend Agent
- Ensures secure JWT handling aur API protection

## Notes
- Always modular
- Integrates with Better Auth, Auth Skill, and DB Skill
