# Validation Skill ✅

## Description
Ye skill user input aur system data ko validate karne ke liye use hota hai. Form validation, API input validation aur data consistency ensure karne ke liye important hai.

## Objective
Provide reusable validation methods jo authentication, database operations aur frontend forms me consistent aur secure data handling ensure kare.

## Capabilities

1. **Email Validation**
   - Correct email format check kare
   - Domain whitelist ya blacklist support

2. **Password Strength**
   - Minimum length, uppercase, lowercase, numbers, special characters
   - Prevent common passwords

3. **Task Input Validation**
   - Title aur description length check
   - Optional fields validation

4. **API Request Validation**
   - Ensure required fields present
   - Type checking aur format checking
   - Reject invalid requests with proper error messages

## Usage
- Frontend forms (signup, signin, task creation)
- Backend FastAPI endpoints
- Used by Auth Skill aur DB operations

## Notes
- Always reusable aur modular
- Must integrate with other skills for secure workflow
