# Frontend Skill 🖥️

## Description
Ye skill Next.js 16+ app development ke liye reusable frontend practices aur components define karta hai.

## Objective
Modern, responsive aur secure frontend banane me help karna jo backend aur agents ke sath seamlessly integrate ho.

## Capabilities

1. **Layouts**
   - Reusable layouts: dashboard, forms, pages
   - Protected routes support

2. **Forms**
   - Signup, signin, task creation forms
   - Client-side validation via Validation Skill

3. **API Calls**
   - Integrates with backend FastAPI endpoints
   - Attaches JWT token in Authorization header
   - Handles errors & loading states

4. **Token Storage Strategy**
   - Stores JWT in secure, client-friendly way (localStorage or cookies)
   - Refresh tokens when expired

5. **Protected Routes**
   - Only logged-in users access certain pages
   - Redirect unauthenticated users to login

## Usage
- Used by Frontend Agent
- Integrates with Auth Skill for secure flows
- Provides reusable components for other features

## Notes
- Follow Next.js 16 App Router conventions
- Use Tailwind CSS for styling
- Client components only when needed
